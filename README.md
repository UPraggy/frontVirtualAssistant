# BH Tour Assistant – Smart Interface ✨

This repository presents the **front-end evolution** of the **BH Tour Assistant**, a chatbot project designed to help users explore cultural and historical points of interest in Belo Horizonte.

## 🎯 Project Focus

The goal of this phase was to **enhance the user interface and experience**, ensuring a clean, intuitive, and responsive layout that works across all devices.

## 🖥️ Interface Highlights

- ✅ **Quick Suggestions:** Button-based shortcuts with common questions for easier navigation.  
- ✅ **Free Input:** Type any question and receive personalized recommendations.  
- ✅ **Real-Time WebSocket Communication:** Instant responses without needing to reload the page.  
- ✅ **UX-Driven Design:** Minimalist, accessible layout with smooth transitions and animations.  
- ✅ **Clean Code Structure:** Refactored from scratch to ensure scalability and maintainability.

## 🔧 Tech Stack

- **Frontend:** React.js  
- **Real-Time Communication:** WebSocket  
- **Design Prototyping:** Figma  
- **Backend (planned/ongoing):** Node.js + NLP for advanced question handling

## 🔮 What's Next

In future iterations, the assistant will go beyond museums to include:
- 🏞️ Parks  
- 🍽️ Gastronomy  
- 🎉 Local Events
